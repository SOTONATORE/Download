# 1. Purpose

Write one prompt for a single still photographic image per segment, with no text, no captions and no watermarks.

# 2. Length

Write one paragraph, with no lists. Make it detailed enough to specify composition, lighting, materials and colours. No word limit is set by the model, so do not add one.

# 3. Composition

Show the subject named in the segment text in a historically plausible late Ottoman setting (1900 to 1922), in 16:9 framing, with one main subject lit by natural light. Keep the subject, the number of subjects, the action and the state exactly as the segment text gives them. State the composition, lighting, materials and colour scheme explicitly.

# 4. Style

Photographic realism with an archival look and muted colours. No cartoon or painting style and no modern objects. Describe the spatial layers (foreground, middle ground, background) where the scene allows.

# 5. Avoid

No text, letters, numbers, logos or signs. No maps, documents or flags as the main subject. No close-up faces unless the segment text names a person. No anachronisms. No metaphors or emotional wording. No meta tags such as "8K", "masterpiece" or "best quality". The word "photorealistic" may appear only inside a sentence that describes the photo, never as a standalone tag. No drawing instructions.

# 6. Output

Return one prompt text only, with no preamble, no quotes and no markdown.
