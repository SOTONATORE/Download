# tools/ — диагностические скрипты

Скрипты для ручной проверки, которые только читают данные и ничего не арендуют, не создают, не меняют и не удаляют.

Главный файл: `vast_probe.py` — проверка доступа к Vast.ai и Hugging Face, поиск предложений и баланс аккаунта. Ключи берутся из окружения.

Скрипты здесь не участвуют в генерации клипов: боевой путь находится в `../core/` и `../cli.py`. Порядок и правила проб описаны в `Generate/SPEC.md` и в отчётах `../reports/`.
