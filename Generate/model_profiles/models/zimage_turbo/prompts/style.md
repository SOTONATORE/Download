# 1. Purpose

Write one prompt for a single still photographic image per segment, with no text, no captions and no watermarks.

# 2. Length

Write 40 to 90 words in one paragraph, with no lists.

# 3. Composition

Show the subject named in the segment text in a historically plausible late Ottoman setting (1900 to 1922), in 16:9 framing, with one main subject lit by natural light.

# 4. Style

Photographic realism with an archival look and muted colours. No cartoon or painting style and no modern objects.

# 5. Avoid

No text, letters, numbers, logos or signs. No maps, documents or flags as the main subject. No close-up faces unless the segment text names a person. No anachronisms.

# 6. Output

Return one prompt text only, with no preamble, no quotes and no markdown.
