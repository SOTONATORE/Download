# worker/ — код воркера на карте Vast.ai

Небольшой HTTP-сервис, который запускается на арендованной карте: принимает задачу (номер клипа, промпт, число кадров, seed), гонит её через локальный headless ComfyUI и отдаёт готовый файл раннеру.

Главные файлы: `server.py` (HTTP-сервис), `comfy_client.py` (клиент ComfyUI), `telemetry.py` (снимки ресурсов), `comfy_output.py` (вывод ComfyUI в журнал), `setup.sh` и `bootstrap.sh` (установка на карте), `Dockerfile`.

Здесь нет логики выбора карт, аренды и уборки (это `../core/`), промптов и релизов. Токен воркера приходит из окружения, в журнал и ответы не попадает. Контракт воркера описан в `Generate/SPEC.md`, раздел 8.
