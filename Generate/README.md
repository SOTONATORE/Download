# Generate/ — вторая часть (генерация клипов по SRT)

Всё, что относится ко второй части, лежит в этой папке, в том числе `SPEC.md` (v0.2) с договорённостями. Структура: ядро в `core/`, точка входа `cli.py`, значения по умолчанию в `config.default.yaml`, профили и стили модели в `model_profiles/`. Ядро не знает про GitHub (SPEC 0.2).

## Как запускать
Всегда из корня репозитория (там же лежат `final.srt` и `missing.txt`):

```
python -m Generate.cli check --srt final.srt --missing missing.txt
python -m Generate.cli run
python -m Generate.cli kill-cards
```

Общие параметры: `--srt` (по умолчанию `final.srt`), `--missing` (по умолчанию `missing.txt`).

Тесты (только стандартная библиотека и pytest, без сети и ключей):

```
python -m pip install -r Generate/requirements-dev.txt   # один раз
python -m pytest Generate/tests
```

## Коды завершения
| Код | Смысл |
|---|---|
| 0 | успех (в том числе «генерировать нечего») |
| 2 | ошибка входных данных до любых трат: нет файла, битый SRT, неверные аргументы |
| 3 | прочая ошибка выполнения, включая «не реализовано» и непредвиденное исключение |

Трейсбеки пользователю не показываются. Для непредвиденных исключений печатается только тип исключения.

## Что реализовано
- `core/srt_parser.py`, `core/timing.py`: перенесены без изменения логики (см. `core/README_srt_timing.md`).
- `model_profiles/prompt_styles/ltx25.md`: инструкция для Gemini (без изменений).
- `cli.py check`: SRT существует и разбирается, `missing` существует (содержимое не разбирается); печатает число сегментов и `srt_hash`.
- `config.default.yaml`: значения по умолчанию (SPEC, раздел 3). Загрузчика конфига пока нет.

## Заглушки
- `cli.py run`: код 3, «Команда ещё не реализована.»
- `cli.py kill-cards`: то же; в будущем короткая команда для шага `if: always()` (SPEC 8.3 (в)).

## Ключи
`cli.py` ключи не читает. В дальнейшем секреты берутся только из окружения (SPEC 0.1) и нигде не печатаются.
